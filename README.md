# Tibyan (تبيان)

![Tibyan Preview](tibyan_pic.png)

A lightweight bilingual (English & Arabic) Windows desktop utility that dispels common misconceptions with subtle notifications.

## How to Download & Run
1. Go to the **[Latest Release](https://github.com/Ibrahim-arius101/Tibyan/releases/latest)** page.
2. Download **`Tibyan_v1.0.zip`** and extract the folder anywhere on your PC.
3. Double-click **`Tibyan.exe`** to launch.

## Updating Misconception Lists
You never need to re-download the app to get newly added facts:
1. Right-click the **Tibyan** icon in your Windows system tray (bottom-right taskbar).
2. Click **Update Misconception Lists**.
3. The latest English and Arabic databases will download automatically.
